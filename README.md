# NodeBlaster Umbrel Community Store

Community App Store for the licensed NodeBlaster Suite and supporting Umbrel utilities.

## Apps

- `nodeblaster-blockchair-bch-mempool`: desktop tile that redirects to the Blockchair Bitcoin Cash mempool transactions page.
- `nodeblaster-control`: unprivileged local control panel for NodeBlaster Suite licensing, host-agent readiness, updates, and display preferences.

## Umbrel setup

Add this repository URL in umbrelOS:

App Store -> three-dot menu -> Community App Store

`https://github.com/cnmne/nodeblaster-umbrel-community-store`

The NodeBlaster Suite app installs without host privileges. Licensed appliance controls require the separately delivered, signed NodeBlaster host agent.
